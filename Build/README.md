# Lost in Tape: Windows build

Izvršljiva datoteka je prevelika za git (GitHub dovoli največ 100 MB na datoteko, igra ima 223 MB), zato je objavljena kot GitHub Release.

**Prenos:** [LostInTape-windows.zip](https://github.com/evasim27/GameJam2026/releases/latest/download/LostInTape-windows.zip)

1. Razširite ZIP.
2. Zaženite `LostInTape.exe`. Vsi podatki igre so vgrajeni v `.exe`, druge datoteke niso potrebne.
3. Če Windows SmartScreen opozori na neznanega izdajatelja, izberite **Več informacij → Vseeno zaženi**.
