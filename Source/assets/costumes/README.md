# Hanging costumes

Four separate costume sprites with transparent backgrounds, generated with the
built-in `image_gen` tool using `Source/game/assets/rewind/cinematic/coat-rack-states.png`
as the visual reference:

- `indiana-jones.png` — Indiana Jones
- `lion-king-simba.png` — Simba from The Lion King
- `pirates-of-the-caribbean-jack-sparrow.png` — Jack Sparrow
- `shrek.png` — Shrek

These are standalone source assets. The foyer continues using its two-state rack
atlas, with Shrek appearing after the second failure.
